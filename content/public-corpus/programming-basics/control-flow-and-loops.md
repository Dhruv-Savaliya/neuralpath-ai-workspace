# Control Flow and Iteration

Control flow determines the order in which individual statements, instructions, or function calls are executed or evaluated within a computer program. Without control flow structures, programs would only execute linearly from beginning to end, limiting their utility.

Conditional statements—such as `if`, `else if`, and `else`—evaluate boolean expressions to determine which branch of logic should execute. In modern programming languages, pattern matching and `switch` statements provide expressive mechanisms for handling multiple discrete states and polymorphic types safely.

Loops and iteration constructs allow code to execute repeatedly until a specific termination condition is reached. While loops evaluate conditions before each iteration, whereas for loops are commonly used to traverse collections, arrays, and iterable sequences. Proper loop termination and bound checks prevent infinite execution loops and buffer overflows.
