# Functions and Modular Code Design

Functions are self-contained blocks of instructions designed to perform a distinct task. By decomposing complex systems into smaller, discrete functions, software engineers achieve code reusability, testability, and clear separation of concerns.

A function signature defines its name, formal parameters, and return type. Pure functions—those that return identical results for identical inputs without producing observable side effects—form the foundation of functional programming and reliable concurrent systems.

Scope and closures determine the accessibility of variables. When a function references identifiers declared in an outer lexical environment, it captures those variables, enabling powerful programming patterns such as partial application, currying, and encapsulation of private state.
